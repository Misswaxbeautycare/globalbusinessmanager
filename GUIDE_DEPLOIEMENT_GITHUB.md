1. Clique sur **`index.html`** (existant)

3. **Supprime tout le contenu** (Ctrl+A, Delete)
4. Ouvre **`index-NOUVEAU.html`** que tu as téléchargé
5. **Copie tout le contenu** (Ctrl+A, Ctrl+C)
6. **Colle dans GitHub** (Ctrl+V)

8. Ajoute message: `Update: nouvelle disposition hamburger`
9. Clique **"Commit"** ✅
